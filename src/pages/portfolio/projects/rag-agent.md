**사내 개발팀 챗봇**은 **클라이언트 PC 자동화**, **서버 기반 RAG 오케스트레이션**, **벡터 DB 기반 지식 검색**을 결합한 플랫폼입니다.

**시스템 구성**:
- **클라이언트 자동화**: 로컬 PC에서 Selenium 기반 회의실 예약, 메일 전송, 메신저 데이터 수집
- **웹 프론트엔드**: Vue.js 기반 자연어 인터페이스
- **백엔드 서비스**: Spring Boot 기반 비즈니스 로직 및 API 통합
- **RAG 오케스트레이션**: FastMCP + LangGraph 기반 AI 에이전트
- **벡터 검색 엔진**: Milvus + Airflow 기반 데이터 수집 파이프라인
- **데이터 레이어**: PostgreSQL (업무 데이터), Redis (세션/캐시/승인토큰)

---

## 🎯 프로젝트 목표

- **엔드-투-엔드 업무 자동화**: 웹 인터페이스부터 클라이언트 PC 자동화까지 전 과정 통합
- **RAG 기반 지식 검색**: Milvus 벡터 DB를 활용한 사내 문서/메신저 데이터 검색
- **하이브리드 아키텍처**: 서버 오케스트레이션 + 클라이언트 실행파일 조합
- **자연어 인터페이스**: 자연스러운 대화로 복잡한 업무 처리

### 주요 구성

**클라이언트 PC**
- 그룹웨어 웹 자동화 (회의실 예약)
- 이메일 클라이언트 제어
- 메신저 데이터 추출

**웹 인터페이스**
- 자연어 입력 폼
- 실시간 응답 표시
- 파일 업로드

**백엔드 서버**
- Notion API 연동
- 그룹웨어 API 연동
- 클라이언트 자동화 중계

**AI 에이전트**
- 자연어 이해 및 의도 파악
- 작업 파라미터 추출
- 벡터 검색 및 답변 생성

**데이터 저장**
- 벡터 DB: 문서/메신저 임베딩
- PostgreSQL: 업무 데이터, 로그
- Redis: 세션, 캐시

## 🔧 핵심 기능

### 1. RAG 기반 지식 검색

**동작 방식**:
- 사용자 질문을 벡터로 변환
- Milvus DB에서 유사 문서 검색
- 검색 결과 기반 답변 생성

**검색 대상**:
- 사내 문서
- 메신저 대화 기록
- 업로드 파일

**사용 예시**:
```
입력: "지난주 회의에서 논의된 배포 일정 알려줘"
→ 메신저/노션 문서 검색
→ 관련 내용 기반 답변 생성
```

---

### 2. 노션 주간회의 자동화

**기능**:
- 최신 주간회의 페이지 자동 탐색
- 전달사항 섹션에 내용 추가
- 날짜 자동 업데이트

**사용 예시**:
```
입력: "주간회의에 배포 일정 추가"
→ 노션 페이지 자동 수정
```

---

### 3. 회의실 예약 자동화

**동작 방식**:
- 자연어에서 예약 정보 추출
- 클라이언트 PC에서 그룹웨어 자동화
- 예약 결과 반환

**사용 예시**:
```
입력: "내일 오후 5시 제안룸1 예약"
→ 날짜/시간 파싱
→ PC에서 자동 예약
```

---

### 4. 메일 전송 자동화

- 이메일 클라이언트 자동 제어
- 수신자, 제목, 본문 자동 입력

---

### 5. 메신저 데이터 수집

- 클라이언트 PC에서 메신저 데이터 추출
- Airflow 파이프라인으로 임베딩 처리
- Milvus DB에 저장하여 검색 가능
