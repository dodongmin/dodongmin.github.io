**내부 RAG 에이전트**는 **Milvus Dense Vector + BM25 재점수화 + RRF**를 활용하여 사내 지식을 검색하고 생성하는 자동화 시스템입니다.  
**LangGraph 라우팅**으로 복잡한 워크플로우를 관리하고, **사내 지식 검색·생성 자동화**를 실현했습니다.

---

## 🧩 핵심 기능

- **하이브리드 검색**: Dense Vector + BM25 + RRF로 정확도 향상
- **지능형 라우팅**: LangGraph 기반 복잡한 워크플로우 관리
- **컨텍스트 관리**: 대화 히스토리 및 관련 문서 자동 관리
- **자동화**: 문서 수집, 임베딩, 인덱싱 파이프라인
- **모니터링**: 검색 성능, 사용 패턴, 품질 지표 추적

---

## 🏗️ 아키텍처 개요

### 검색 엔진
- **Vector Store**: Milvus (Dense Vector 저장 및 검색)
- **Text Search**: BM25 (키워드 기반 검색)
- **Fusion**: RRF (Reciprocal Rank Fusion)로 결과 통합
- **Ranking**: 재점수화로 최종 결과 순위 결정

### AI 파이프라인
- **Embedding**: OpenAI/Cohere API 또는 로컬 모델
- **LLM**: GPT-4/Claude 또는 로컬 모델 (Ollama)
- **Orchestration**: LangGraph로 복잡한 워크플로우 관리
- **Memory**: 대화 히스토리 및 컨텍스트 관리

---

## 🔍 검색 전략

### 하이브리드 검색 파이프라인
1. **Dense Vector 검색**: 의미적 유사도 기반 검색
2. **BM25 검색**: 키워드 매칭 기반 검색
3. **RRF 통합**: 두 결과를 가중 평균으로 결합
4. **재점수화**: 추가 신호로 최종 순위 조정

### 검색 최적화
- **쿼리 확장**: 동의어, 관련어 자동 추가
- **필터링**: 문서 타입, 날짜, 부서별 필터
- **개인화**: 사용자별 검색 히스토리 기반 추천
- **A/B 테스트**: 검색 알고리즘 성능 비교

---

## 🤖 AI 에이전트 워크플로우

### LangGraph 기반 라우팅
- **Intent 분류**: 사용자 의도 파악 (검색/생성/요약/번역)
- **컨텍스트 수집**: 관련 문서 및 이전 대화 수집
- **프롬프트 생성**: 동적 프롬프트 템플릿 생성
- **응답 생성**: LLM을 통한 최종 응답 생성
- **검증**: 응답 품질 및 정확성 검증

### 워크플로우 예시
1. **질문 분석**: 사용자 질문의 의도 및 엔티티 추출
2. **문서 검색**: 관련 문서를 하이브리드 검색으로 수집
3. **컨텍스트 구성**: 검색된 문서를 LLM 컨텍스트로 구성
4. **응답 생성**: 프롬프트 + 컨텍스트로 답변 생성
5. **후처리**: 응답 포맷팅 및 소스 문서 링크 추가
