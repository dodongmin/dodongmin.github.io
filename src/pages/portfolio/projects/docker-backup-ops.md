**Docker 백업 컨테이너 & 운영 표준화**는 안정적인 데이터 백업을 위한 Docker 컨테이너 설계 및 배포, 운영 절차 표준화 프로젝트입니다.  
다양한 환경에서의 **백업 호환성** 및 **자동화 구현**을 통해 운영 효율성을 크게 향상시켰습니다.

---

## 🧩 핵심 기능

- **멀티 DB 지원**: PostgreSQL, MySQL, MariaDB 통합 백업 솔루션
- **컨테이너화**: Docker 기반으로 환경 독립적 백업 실행
- **자동화**: 스케줄링, 압축, 암호화, 전송까지 원클릭 처리
- **표준화**: 운영 절차 문서화 및 스크립트 자동화
- **모니터링**: 백업 상태 추적 및 실패 알림 시스템

---

## 🏗️ 아키텍처 개요

### 백업 컨테이너 구조
- **Base Image**: Alpine Linux + 필수 도구 (pg_dump, mysqldump, gzip, openssl)
- **스크립트 엔진**: Bash + Python으로 복잡한 로직 처리
- **설정 관리**: 환경변수 기반 동적 설정
- **로그 시스템**: 구조화된 로그 및 에러 추적

### 배포 전략
- **Docker Compose**: 로컬 개발 환경
- **Kubernetes**: 프로덕션 환경 배포
- **CI/CD**: GitHub Actions 기반 자동 빌드/배포

---

## 💾 백업 전략

### 데이터베이스별 백업 방식
- **PostgreSQL**: pg_dump + pg_dumpall (전체/스키마별)
- **MySQL/MariaDB**: mysqldump + binary log 백업
- **압축**: gzip/bzip2로 저장 공간 최적화
- **암호화**: OpenSSL AES-256으로 보안 강화

### 백업 스케줄링
- **전체 백업**: 주간 (일요일 새벽)
- **증분 백업**: 일일 (평일 새벽)
- **로그 백업**: 시간별 (트랜잭션 로그)
- **보존 정책**: 30일/90일/1년 단계별 보관

---

## 🔧 운영 자동화

### 스크립트 표준화
- **백업 스크립트**: 표준 템플릿 + 환경별 커스터마이징
- **복원 스크립트**: 단계별 복원 가이드 + 자동화
- **검증 스크립트**: 백업 무결성 체크 + 알림
- **정리 스크립트**: 오래된 백업 파일 자동 삭제

### 모니터링 & 알림
- **상태 체크**: 백업 성공/실패 모니터링
- **용량 관리**: 디스크 사용량 추적
- **성능 지표**: 백업 시간, 압축률, 전송 속도
- **알림 시스템**: Slack/Email 통합

---

## 📋 운영 표준화 (SOP)

### 백업 프로세스
1. **사전 체크**: 디스크 공간, 네트워크 연결, DB 상태
2. **백업 실행**: 데이터베이스별 최적화된 백업 명령
3. **검증**: 백업 파일 무결성 및 크기 확인
4. **전송**: 원격 저장소로 안전한 전송
5. **정리**: 로컬 임시 파일 정리 및 로그 기록

### 복원 프로세스
1. **환경 확인**: 복원 대상 환경 상태 점검
2. **백업 선택**: 복원할 백업 버전 선택
3. **사전 백업**: 현재 데이터 보호용 백업
4. **복원 실행**: 단계별 복원 및 검증
5. **서비스 재시작**: 애플리케이션 서비스 복구
