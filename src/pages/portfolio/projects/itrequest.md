**사내 요청 게시판**은 사내에서 발생하는 **오류 신고, 견적 의뢰** 등을 체계적으로 관리하기 위해 개발된 **Spring Boot 기반 웹 애플리케이션**입니다.

---

## 🎯 핵심 목표

- **통합 관리**: 요청을 단일 플랫폼에서 관리
- **프로세스 가시화**: 요청 상태를 실시간으로 추적 (접수대기 → 작업필요 → 처리완료)
- **효율적인 업무 분배**: 담당자 배정 및 부서별 필터링
- **알림 시스템**: 텔레그램 연동으로 즉각적인 알림

## 🔧 핵심 기능

### 1. 요청서 관리
- **상태 관리**: 접수대기 → 작업필요 → 처리완료 → 보류 / 반려
- **첨부파일**: 다중 파일 업로드 및 관리

### 2. 댓글 및 답변
- **계층형 구조**: 댓글 + 답글 2단계
- **Summernote 에디터**: WYSIWYG 리치 텍스트 작성
- **권한 제어**: 본인 작성 댓글만 수정/삭제

### 3. 알림 시스템
- **SMS**: 상태 변경 시 요청자 및 담당자에게 발송
- **Telegram Bot**: 신규 요청 및 긴급 요청 실시간 알림

### 4. 권한 관리
| 권한 | 기능 |
|-----|------|
| USER | 요청서 작성, 본인 요청 수정/삭제 |
| MANAGER | 모든 요청 조회, 댓글 작성 |
| ADMIN | 상태 변경, 담당자 배정, 사용자 관리 |
